# DashInsight

Local delivery-lab console for a non-root Android device running Termux. Scores imported offer exports, probes loopback ports, tracks process telemetry, and maps lab devices by serial. No root, no hidden pairing, no third-party marketplace automation.

Operator offer files are imported by the operator. The app does not sign into DoorDash or any other marketplace.

Full source for 1.0.0 is in this commit series under dashinsight/, tests/, and release/.
